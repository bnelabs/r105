## r105 0.8.3

This release replaces the ad hoc slash-command connection flow with guided
provider and model setup.

### Guided connections

- `/connect` and `/provider` now open a provider picker.
- Choose a predefined local or cloud connection, enter an API key when needed,
  load the provider's live model list, and select the model before applying it.
- OpenCode Zen and OpenCode Go are included alongside llama.cpp, llama-router,
  Ollama, LM Studio, vLLM, OpenAI, Groq, OpenRouter, DeepSeek, Together, and
  custom OpenAI-compatible endpoints.
- Credentials stay in memory for the session. Provider metadata, URL, backend,
  and selected model are saved without API keys.

### Compatibility

The release keeps the existing binary and native package matrix: Linux x86_64,
macOS x86_64 and arm64, Windows x86_64 and arm64, FreeBSD amd64, Ubuntu/Debian
amd64, Fedora/RHEL x86_64, Arch Linux x86_64, and Alpine Linux x86_64 (musl).
