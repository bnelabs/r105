# r105 1.1.0

r105 1.1.0 makes the TUI faster to drive: attach files with `@`, run shell
with `!`, steer running requests, and undo exchanges that went sideways.

## Highlights

- `@file` references with fuzzy completion attach workspace files and
  directory listings to the prompt as context.
- `!` runs a shell command inside the sandbox boundary and attaches its
  output to the conversation.
- Enter while a request is active steers it; Alt+Enter queues a follow-up.
  A terminal bell reports when a request fully settles (`/attention`).
- `/undo` drops the last exchange and restores its prompt for rephrasing;
  `/redo` re-applies it. `/session fork <name>` branches a thread safely.
- `/settings` gathers theme, permissions, reasoning, and toggles in one
  overlay; `/editor` composes prompts in `$EDITOR`.
- `/thinking` shows, hides, or collapses the model's thinking blocks.
- The footer reports session tokens (`↑in ↓out`), the git branch, and input
  hints; the header shows the sandbox backend and skill count.
- The five Ctrl shortcuts remap through `keybindings` in config.json.
- Hardening fixes: Unicode-safe session search, strict session roles,
  provider-id llama.cpp detection, real-port router inference, side-effect
  free path resolution, calculator depth guards, Docker guest paths, MCP
  warnings, and posture-gated plugins.

See [README.md](../../README.md) for the full command surface and
configuration reference.
