# r105 2.5.0

r105 2.5.0 makes the terminal workspace persistent and easier to navigate:
conversation-first rendering, nested split panes, and session-backed tab
management now work together without exposing internal bookkeeping in the
transcript.

## Highlights

- **Answer-first transcript.** Prompts render with `>` and replies with `●`.
  Reasoning and tool output stay compact and expandable, so internal traces do
  not interrupt the conversation.
- **Nested split panes.** `Ctrl+Shift+D` splits to the right and
  `Ctrl+Shift+E` splits below. The layout supports mixed nested splits, up to
  four live sessions, directional focus, click-to-focus, active separators,
  and `Ctrl+Shift+Enter` focused-pane zoom.
- **Persistent tabs.** `Ctrl+Shift+T` opens a tab, `Ctrl+Tab` cycles,
  `Alt+1..9` selects, `Alt+Shift+←/→` reorders, and the active tab exposes a
  clickable `×`. Every pane autosaves its own session; tab switches and
  restarts restore the pane layout and focus.
- **Shell integration.** Recognized bash, zsh, and fish sessions parse OSC
  markers for command boundaries, cwd, and interactive exit status, while
  unsupported shells keep the honest unknown-status fallback.
- **Window hardening.** Native window redraw retries are bounded and paced
  when the GPU surface is unavailable, and explicit window session names now
  restore the requested session instead of creating a new one.

## Verification

The release gate covers formatting, locked checks, Clippy, unit/integration
tests, cross-platform archives and packages, checksums, and the native window
smoke paths. The local release build passed the 2.5.0 validation suite before
the tag was created.
