# r105 2.0.0

r105 2.0.0 is the trust release: the agent keeps its new capabilities,
but every destructive action now passes a human checkpoint first — and
the composer gets a local neural assist that never phones home. It also
carries the 1.4.x debt payoff (UI module split, Python legacy removal),
which is why it is a major version: commands, tools, and config keys
were removed.

## Highlights

- **Modes with teeth.** Plan allows reads and web research but refuses
  writes and execution; ask answers without tools. The mode persists in
  the session file, syncs to the Tab label on load, and ships a prompt
  preamble so the model does not spam denied calls. The decorative mode
  is gone.
- **Per-action approvals.** Per-category `approval_exec/write/read/
  network/mcp/plugin` levels plus `command_allowlist` /
  `command_denylist` regexes. `ask` calls pause on an inline card
  (`y` once, `a` always this run, `n` deny); enforcement re-runs inside
  `execute`, so no code path bypasses the card. Ask-by-default covers
  code execution, file writes, MCP, and plugins.
- **Visible task list.** The model-maintained `todo_write` tool renders
  a collapsible TASKS section with `tasks done/total` in the footer —
  cheap agentic feel on long tasks, reusable section machinery.
- **Ghost-text completion.** `!` and `/sh` lines debounce into a local
  `llama-server` sidecar running Qwen2.5-Coder-0.5B (Q8_0 GGUF):
  ~350ms warm on an M1, ~578MB resident, live-verified against exact
  completions (`docker ps --format` → the Go template). Tab accepts,
  Esc dismisses, every failure falls back silent to the deterministic
  menus. `/completion [status|start|stop]` manages the sidecar; weights
  default to `<config>/models/qwen2.5-coder-0.5b-q8_0.gguf` and are never
  auto-downloaded.
- **Debt paid.** The 5,386-line `src/ui.rs` is now six modules with no
  logic change, and the Python bridge, `execute_python`, `/approve`,
  `/bridge`, and two config keys are deleted, not deprecated.

## Breaking changes

- Removed: `execute_python` tool, `/approve` and `/bridge` commands,
  the `r105 bridge` subcommand, `python_bridge_command` and
  `auto_approve_execute_python` config keys. `execute_rust` is the
  sandboxed code-execution tool.
- New required behavior: tools gated by mode and approvals fail closed
  outside the TUI (`ask` behaves as deny with a message).

## Setup for ghost text

```sh
curl -L -o ~/.config/r105/models/qwen2.5-coder-0.5b-q8_0.gguf \
  https://huggingface.co/ggml-org/Qwen2.5-Coder-0.5B-Q8_0-GGUF/resolve/main/qwen2.5-coder-0.5b-q8_0.gguf
# plus: brew install llama.cpp   (provides llama-server)
```

Type `!git checkout -b feat/` and pause — r105 starts the sidecar on
first use and `/completion` reports its status.

See [README.md](../../README.md) for the full command surface and
configuration reference. Specs 0010–0015 under `docs/specs/` record
every change.
