## r105 0.7.0

This release packages the terminal assistant as Python distributions, native
Linux and FreeBSD packages, and standalone executables. Every published asset
has a matching entry in `SHA256SUMS`.

### Compatibility

| Operating system | Architecture | Release asset |
| --- | --- | --- |
| Linux (glibc; Ubuntu/Debian, Arch, Fedora/RHEL) | x86_64 / amd64 | `.deb`, `.pkg.tar.zst`, `.rpm`, or `r105-linux-x64.tar.gz` |
| Alpine Linux (musl) | x86_64 | `.apk` when the native Alpine build succeeds |
| FreeBSD 14 | amd64 | `.pkg` |
| macOS | x86_64 | `r105-macos-x64.tar.gz` |
| macOS | arm64 | `r105-macos-arm64.tar.gz` |
| Windows | x86_64 | `r105-windows-x64.zip` |
| Windows 11 | arm64 | `r105-windows-arm64.zip` |

The Python package supports Python 3.12 and newer on platforms supported by
its dependencies. The Linux distribution packages target x86_64/amd64. The
Alpine package uses musl and is published separately from the glibc Linux
assets when its native build is available.

See [CHANGELOG.md](https://github.com/bnelabs/r105/blob/v0.7.0/CHANGELOG.md)
for the complete change list and [README.md](https://github.com/bnelabs/r105/blob/v0.7.0/README.md)
for installation instructions.
