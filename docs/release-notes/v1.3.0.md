# r105 1.3.0

r105 1.3.0 borrows the best ideas from pi and Warp — custom commands,
smarter completion, typo forgiveness, and plain-words shell drafts —
reimplemented in r105's Rust style.

## Highlights

- **Custom slash commands from Markdown.** Drop `name.md` files in
  `~/.config/r105/commands/` (global) or `<workspace>/.r105/commands/`
  (project) and each becomes a `/name` command with `$1`, `$@`,
  `${N:-default}`, and slice substitution. Listed in the `/` palette
  (marked `*`), covered by `/help`, managed with `/commands [reload]`.
  Built-ins always win name collisions, and shadowing is reported.
- **Argument completion.** `/theme <Tab>`, `/model <Tab>`, `/skill use
  <Tab>`, `/session load <Tab>`, `/preview <Tab>`, `/connect <Tab>` —
  values complete inline with a Tab-accept popup.
- **Did-you-mean.** Unknown slash commands suggest the closest match
  across built-ins and customs instead of a bare error.
- **`/sh <request>`.** Describe the shell command in plain words; the
  model drafts one line and the composer prefills it with `!` for
  review. Nothing runs without an explicit Enter, so posture gates and
  the sandbox apply unchanged.
