# r105 1.0.2

r105 1.0.2 makes local and self-hosted inference endpoints configurable from
the provider menu.

## Highlights

- The guided provider picker now asks for an endpoint when selecting
  llama-router, llama.cpp, Ollama, LM Studio, or vLLM.
- Empty endpoint input preserves each connector's local loopback default.
- LAN hostnames and IP addresses are accepted, validated, probed through model
  discovery, and saved only after a successful connection.
- Cloud provider flows remain unchanged and continue to use their credential
  prompts and fixed cloud endpoints.

See [README.md](../../README.md) for provider and self-hosted endpoint setup.
