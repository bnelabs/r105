# r105 1.0.1

r105 1.0.1 is a native compatibility and hardening patch for the Rust AI
harness. It keeps the small Rust binary and native package matrix while making
legacy workflows easier to carry forward.

## Highlights

- Optional external Python bridge for legacy `execute_python` workflows. The
  reference bridge is stdlib-only, approval gated, timeout bounded, and kept
  outside the native binary and package dependency tree.
- Restored the legacy state, profile, history, quality, JSON, config,
  autocompact, reasoning, permissions, approval, preview, and bridge slash
  commands in the Ratatui TUI.
- `--yes` now carries its Python approval behavior into the interactive TUI.
- External bridge command parsing preserves Windows drive and UNC paths and
  never invokes a shell.
- Subprocess output is bounded while it is read, and IPv4-mapped IPv6 private
  addresses are rejected by the web tool SSRF guard.

## Compatibility

The release includes the same assets as 1.0.0: Linux x86_64/aarch64,
macOS x86_64/arm64, Windows x86_64/arm64, Ubuntu/Debian, Arch, Fedora/RHEL,
FreeBSD amd64, and Alpine x86_64. Install Python bridge support separately by
configuring `R105_PYTHON_BRIDGE` or `python_bridge_command`; normal native
installations remain Python-free.

See [README.md](../../README.md) for provider and bridge setup.
