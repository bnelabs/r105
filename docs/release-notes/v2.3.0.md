# r105 2.3.0

r105 2.3.0 makes the composer behave like a modern terminal surface.
Shell-looking lines run on Enter with no marker, `#` describes what you
want in plain language, Ctrl+R searches history in reverse, tabs
organize sessions — and a tab can hold up to
four panes, each a genuinely live session that keeps streaming while
you work in its sibling. The layout got lighter and quieter to match.

## Highlights

- **Split panes.** Ctrl+Shift+D opens a fresh session beside the
  focused one, up to four per tab. Ctrl+Shift+←/→ (or Ctrl+Alt+←/→)
  moves focus, a click focuses the pane under the pointer, and the
  wheel scrolls the pane it hovers. Each pane owns its composer,
  transcript, queue, status, and cancellation: a background pane keeps
  generating while you type in its sibling, its frame shows `…` while
  running and `•` when it finishes unseen. Ctrl+Shift+W closes the
  pane (the last pane closes its tab), and tab switches stash the whole
  layout — every pane autosaves its session, so a restored split comes
  back with both transcripts and focus.
- **Tabs.** Ctrl+Shift+T opens a session-backed tab, Ctrl+Tab and
  Ctrl+Shift+Tab cycle, Alt+1..9 select, clicks work, and the bar
  persists to `tabs.json` and restores on startup.
- **Terminal-style Enter.** A shell-looking line runs when submitted — no
  `!` needed. `cd <dir>` retargets the workspace; prose, questions, and
  `/` commands keep their paths. Shell lines color as you type, and the
  composer announces `Shell · Enter runs` whenever the line would
  execute.
- **Ctrl+R reverse history search.** The draft seeds the query, typing
  narrows, ↑↓ and the wheel move the highlight, the composer previews
  the match live, Enter accepts without running, Esc restores the
  draft.
- **Natural-language `#`.** Describe what you want (`# list large
  files`) and the model drafts one shell command into the composer for
  review — `#!` and `/sh` are gone.
- **Completion intelligence.** Marker-free detection ghosts plain
  `git check` lines; rows carry curated one-line docs; live values come
  from background daemon queries (kubectl pods/namespaces, docker
  containers/images) with a 60s TTL and failure backoff; a model ghost
  proposes the rest of an idle shell line behind the local cascade.
- **Lighter layout.** A one-row tab bar replaces the two-row header,
  the composer lost its box for a hairline rule, the conversation
  dropped its rails and block rules for blank spacing, and the footer
  carries the workspace, sandbox, and context bar. The session view is
  no longer called a transcript anywhere in the UI.

Panes required moving each session's runtime behind a `Pane` owner with
pane-addressed events, so background work streams, settles, and cancels
independently — one live session per pane, at chat scale.
