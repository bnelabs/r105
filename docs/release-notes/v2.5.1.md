# r105 2.5.1

r105 2.5.1 makes the native window easier to understand and safer to use
across desktop platforms, while clarifying the command-line entrypoints.

## Highlights

- **Versioned desktop menu.** The native window reserves a top menu row from
  the PTY grid and provides the same Help and About surfaces on macOS, Linux,
  Windows, and other desktop targets.
- **Professional About metadata.** The macOS application menu and app bundle
  identify the installed version and say “Built by BNE Labs”; the in-window
  About surface carries the same information everywhere.
- **Native application icon.** A shared midnight, cyan, and amber r105 mark is
  embedded in native windows on every desktop target and emitted as a multi-size
  macOS app icon.
- **Complete Help surface.** F1, the Help menu, and the native menu reference
  cover composer, terminal, answer reading, clipboard, approval, and command
  controls.
- **Clear startup commands.** `r105` starts the interactive workspace in the
  current terminal, `r105 run` is the explicit form, `r105 window` opens an
  independent desktop window, and `r105 terminal` starts a standalone shell
  session.

## Verification

The release gate covers formatting, locked checks, Clippy, unit/integration
tests, platform release builds, package metadata, and native-window smoke
frames. The deterministic local gate passed before the tag was created.
