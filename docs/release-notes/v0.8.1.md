## r105 0.8.1

This patch release hardens the release pipeline after the 0.8.0 provider and
llama.cpp update.

### Reliability fixes

- CI type checking now passes for provider switching and live client
  reconfiguration.
- Alpine package builds install the generated public signing key before
  creating the temporary repository index.
- Release notes are selected from the matching versioned release-notes file.
- Homebrew formula synchronization configures authenticated Git transport for
  the tap update.

### Compatibility

The published release includes a portable Linux x86_64 binary, macOS x86_64
and arm64 binaries, Windows x86_64 and arm64 binaries, and a FreeBSD amd64
package. Native distro packages are available for Ubuntu/Debian amd64, Arch
Linux x86_64, Fedora/RHEL x86_64, FreeBSD amd64, and Alpine Linux x86_64
(musl).
