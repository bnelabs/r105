## r105 0.8.2

This patch release improves slash-command navigation on terminal renderers and
hardens the Alpine package validation path.

### TUI fix

- The highlighted slash command now scrolls into view with one clear row below
  it, preventing the selection from being clipped against the bottom border on
  Windows terminals.

### Alpine packaging

- The Alpine smoke check extracts the native musl package payload and runs
  `r105 --version` without trying to resolve runtime dependencies in an empty
  offline root.

### Compatibility

The published release includes a portable Linux x86_64 binary, macOS x86_64
and arm64 binaries, Windows x86_64 and arm64 binaries, and a FreeBSD amd64
package. Native distro packages are available for Ubuntu/Debian amd64, Arch
Linux x86_64, Fedora/RHEL x86_64, FreeBSD amd64, and Alpine Linux x86_64
(musl).
