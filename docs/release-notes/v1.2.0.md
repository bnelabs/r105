# r105 1.2.0

r105 1.2.0 removes the guesswork around slow first responses: cold router
loads no longer look like hung requests.

## Highlights

- The `/models` picker shows each model's provider load state next to the
  active marker, so unloaded models are visible before the first prompt.
- Connecting warns when a pick needs a first-use load.
- A request with no first token after 15 seconds says so once — the server
  may be loading the model — instead of leaving a stale Sending status.
  The hint covers prompts and compactions, and Esc still cancels.

See [README.md](../../README.md) for the full command surface and
configuration reference.
