# r105 2.2.0

r105 2.2.0 turns the completion cascade into a full suggestion system
and adds a session pane. Shell lines get context-aware ghosts, a
Tab-opened completion menu, alias expansion, and post-failure fixes —
all offline, all from local files. Ctrl+B opens a left column for
opening and managing sessions and workspaces without losing work.

## Highlights

- **Shell Tab menu.** Tab on a `!`/`/sh` line applies the single match
  at once or opens a navigable menu when ambiguous: recent history
  first, then subcommands, flags, branches, scripts, and files, each
  tagged with its kind. ↑↓ move, Tab fills, Esc closes.
- **Alias expansion.** Rc-file aliases and gitconfig aliases expand
  before spec lookup, so `g st` completes as git and `git co` offers
  checkout's branches.
- **Deeper specs.** Twenty commands, nested verbs (`gh issue list`,
  `docker container ls`, `git stash pop`), kubectl resource types,
  and bare-filename completion.
- **Ranked corrections.** A failed `!` line offers up to three fixes;
  → applies the best, alternates list in the transcript.
- **Session pane.** Ctrl+B toggles a left column of saved sessions and
  recent workspaces. Switching autosaves the live transcript first,
  so the pane never discards work.
- **Leaner composer.** Mouse on by default, IDE editing keys, block
  cards with click-to-collapse, professional-minimal wording.

Terminal work is repetitive — context beats parameters. Specs 0015,
0016, and 0018 under `docs/specs/` record the findings behind the
cascade, the menus, and the single-owner rule.
