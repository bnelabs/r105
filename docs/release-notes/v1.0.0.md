# r105 1.0.0

r105 1.0.0 is the Rust-native release. It packages one small executable for
supported platforms and removes the Python runtime from installation,
Homebrew, Scoop, Docker, and distribution package paths.

## Highlights

- Focused Ratatui TUI with visible context usage, mode switching, queued
  prompts, cancellable work, task details, and scroll-safe slash pickers.
- Guided `/connect` flow for OpenCode, OpenCode Go, llama.cpp, llama-router,
  Ollama, LM Studio, vLLM, OpenAI, Groq, OpenRouter, DeepSeek, Together, and
  custom OpenAI-compatible endpoints.
- Native streaming HTTP/SSE, model discovery, router metadata, and llama.cpp
  `cache_prompt` support.
- Native tools, bounded calculation, workspace-safe file tools, redirect and
  DNS-safe web fetching, MCP stdio/HTTP, executable Rust plugins, sessions, and
  dependency-free exports.
- Compatibility reads for existing r105 0.8.x config and session JSON, with
  versioned atomic session writes.
- Release artifacts for Linux x86_64/aarch64, macOS x86_64/arm64, Windows
  x86_64/arm64, FreeBSD amd64, Ubuntu/Debian, Arch, Fedora/RHEL, and Alpine
  x86_64 when the musl package job succeeds.
